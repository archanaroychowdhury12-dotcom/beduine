How Lucky Draw will execute
How Beduin Lucky Draw Will Be Conducted
Data Collection & Verification
All subscriptions made during the week (up to Saturday 11:59 PM) are collected.
Each subscriber is assigned a unique ticket ID / number.
Duplicate or invalid entries (unverified payments, fake accounts) are filtered out.
Final subscriber list is frozen for that week’s draw.
Winner Count Calculation
Total number of active subscribers = N.
Winners = 5% of N (rounded up).
Example: 1047 subscriber’s → 52.35 → 53 winners.
Example: 1051 subscriber’s → 52.55 → 53 winners.
Formula: Winners = ROUNDUP (N × 0.05, 0)
Random Selection Process
Random number generator (RNG) software is used to pick winners.
Example: Random.org, Google Random Picker, or an in-house secured system.
The RNG is run live or recorded with screen share for full transparency.
The selected Ticket IDs = Final Winners.
Transparency & Proof
The entire draw is screen recorded or lives streamed (FB / YouTube)
A winner report (CSV / PDF) is generated with:
Total subscribers
Total winners selected
List of winner IDs / Names
Date & Time of draw
RNG seed / verification log
Report is saved in company records for audit.
Winner Announcement
Winners are announced every Sunday evening via:
Company Website (Winners Page)
Social Media (FB, Instagram, WhatsApp groups)
SMS & Email notification
Example SMS:
Congratulations [Name]! You are a Beduin Lucky Draw Winner! Your coupon: BEDWIN-JULY-12345. Call ‪+91 8768903565‬ for details.
Post-Draw Process
Each winner gets a unique digital coupon code (QR/UUID) stored in the company system.
Winners are grouped into their quarterly tour batch (Jan–Mar → July, Apr–Jun → October, etc.).
Non-winners get reminder SMS about their discount benefits (₹500 × 1/2/4 depending on plan).
Why Customers Will Trust the System
Always Round Up Rule: ensures fairness (more winners, never less).
Digital RNG + Live/Recorded Proof: no manual manipulation.
Public Announcements: winners’ names are visible, transparent.
Coupon Codes: secure, unique, cannot be duplicated.
So the customer knows: “Every Sunday, Beduin runs a fair digital draw. If I win, I travel free. If not, I still get discounts. Either way, I gain.”

M. Discount Credit Category-Locking Logic
This section must be applied to the subscription system, checkout flow, user dashboard, admin panel, Demo Wallet flow, and credit transaction history.
1. Discount Credit Value Rules
Domestic Discount Credit
- Domestic plan credits are Domestic Discount Credits.
- Each Domestic Discount Credit value = ₹500.
- Domestic Discount Credits can only be used for Domestic bookings/plans.
- Domestic Discount Credits cannot be used for International bookings/plans.
International Discount Credit
- International plan credits are International Discount Credits.
- Each International Discount Credit value = ₹5,000.
- International Discount Credits can only be used for International bookings/plans.
- International Discount Credits cannot be used for Domestic bookings/plans.
2. Important Restriction
- A user must not be able to use International Discount Credits to get a discount on any Domestic plan, Domestic package, Domestic booking, or Domestic checkout.
- A user must not be able to use Domestic Discount Credits to get a discount on any International plan, International package, International booking, or International checkout.
3. Credit Issuing Logic
Domestic Plans
- Issue credits with credit_category = "domestic".
- Issue credits with credit_value = 500.
- Issue credits with usable_for = "domestic_only".
International Plans
- Issue credits with credit_category = "international".
- Issue credits with credit_value = 5000.
- Issue credits with usable_for = "international_only".
4. International Plan Credit Logic
- Silver International ₹4,999: discount_credit_count = 1, credit_value = ₹5,000, total_discount_value = ₹5,000.
- Gold International ₹7,999: discount_credit_count = 2, credit_value = ₹5,000, total_discount_value = ₹10,000.
- Platinum International ₹14,999: discount_credit_count = 4, credit_value = ₹5,000, total_discount_value = ₹20,000.
5. Domestic Plan Credit Logic
- For all Domestic plans, each issued Discount Credit must have a value of ₹500.
- Do not mix Domestic and International credit values.
6. Checkout Validation
During booking or subscription checkout:
- Detect whether the selected checkout item is Domestic or International.
- If checkout item type = domestic, only allow credits where credit_category = "domestic".
- If checkout item type = international, only allow credits where credit_category = "international".
- If the user tries to apply the wrong credit type, block it and show a clear error message.
Error message for using International DC on Domestic checkout:
- "International Discount Credits can only be used for International bookings."
Error message for using Domestic DC on International checkout:
- "Domestic Discount Credits can only be used for Domestic bookings."
7. Dashboard Display
- Show Domestic and International credits separately.
- Do not combine Domestic and International credits into one total without category labels.
Domestic Discount Credits dashboard block must show:
- Available credits.
- Value per credit: ₹500.
- Total domestic discount value.
- Usable only for Domestic bookings.
International Discount Credits dashboard block must show:
- Available credits.
- Value per credit: ₹5,000.
- Total international discount value.
- Usable only for International bookings.
8. Database Suggested Fields
Add or update these fields in the credits table:
- credit_category: domestic / international
- credit_value: 500 for domestic / 5000 for international
- usable_for: domestic_only / international_only
- source: real / demo
- status: available / used / expired
9. Validation Rules
- Domestic DC value must always be ₹500.
- International DC value must always be ₹5,000.
- International DC cannot be applied to Domestic checkout.
- Domestic DC cannot be applied to International checkout.
- Demo Wallet and real payment flow must both follow the same credit category rules.
- Admin panel must show credit category clearly.
- Credit transaction history must show whether the credit is Domestic or International.
10. Testing Checklist
1. Buy a Domestic plan.
2. Confirm issued credits are Domestic DC with ₹500 value each.
3. Buy an International plan.
4. Confirm issued credits are International DC with ₹5,000 value each.
5. Try to use International DC on a Domestic booking and confirm the system blocks it.
6. Try to use Domestic DC on an International booking and confirm the system blocks it.
7. Confirm dashboard shows Domestic and International credits separately.
8. Confirm demo subscription and real subscription both follow the same restriction.
