108 [ListParagraph] How Beduin Lucky Draw Will Be Conducted
109 [ListParagraph] Data Collection & Verification
110 [] All subscriptions made during the week (up to Saturday 11:59 PM) are collected.
111 [] Each subscriber is assigned a unique ticket ID / number.
112 [] Duplicate or invalid entries (unverified payments, fake accounts) are filtered out.
113 [] Final subscriber list is frozen for that week’s draw.
114 [ListParagraph] Winner Count Calculation
115 [] Total number of active subscribers = N.
116 [] Winners = 5% of N (rounded up).
117 [] Example: 1047 subscriber’s → 52.35 → 53 winners.
118 [] Example: 1051 subscriber’s → 52.55 → 53 winners.
119 [] Formula: Winners = ROUNDUP (N × 0.05, 0)
120 [ListParagraph] Random Selection Process
121 [] Random number generator (RNG) software is used to pick winners.
122 [] Example: Random.org, Google Random Picker, or an in-house secured system.
123 [] The RNG is run live or recorded with screen share for full transparency.
124 [] The selected Ticket IDs = Final Winners.
125 [ListParagraph] Transparency & Proof
126 [] The entire draw is screen recorded or lives streamed (FB / YouTube)
127 [] A winner report (CSV / PDF) is generated with:
128 [] Total subscribers
129 [] Total winners selected
130 [] List of winner IDs / Names
131 [] Date & Time of draw
132 [] RNG seed / verification log
133 [] Report is saved in company records for audit.

135 [] Winners are announced every Sunday evening via:
